# Statistical Analysis of the Academic Performance of 10 Students

## About the Project

This project presents a statistical analysis of the academic performance of 10 students in Mathematics, Physics, and Statistics.

The project was developed using Python and Pandas and applies descriptive statistical methods to analyse educational data.

## Objectives

- Analyse the academic performance of 10 students.
- Calculate the mean, median and standard deviation.
- Calculate the overall average of each student.
- Determine the overall pass rate.
- Visualise the results using graphs.
- Demonstrate the application of Mathematics, Statistics and Python to a practical data analysis problem.

## Dataset

The dataset contains fictional academic scores for 10 students in three subjects:

- Mathematics
- Physics
- Statistics

The data are used exclusively for educational and portfolio purposes.

## Technologies

- Python
- Pandas
- Matplotlib
- Descriptive Statistics
- Google Colab

## Main Results

The analysis shows a 100% overall pass rate for the 10 students.

The project includes:

- Descriptive statistics
- Individual student averages
- Pass/Fail classification
- Subject-level performance analysis
- Data visualisation
